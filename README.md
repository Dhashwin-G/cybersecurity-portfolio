About Me:

I am a cybersecurity student and aspiring security professional with a strong interest in ethical hacking, penetration testing, web security, and security research.

I enjoy learning by building and testing things in controlled and authorized environments rather than relying only on theory. My hands-on experience includes working with Kali Linux, Python, Nmap, Burp Suite, SQLMap, WPScan, Gobuster, Subfinder, HTTPx, and other security tools, along with platforms such as TryHackMe and Hack The Box.

I am particularly interested in understanding how systems work, identifying security weaknesses, and learning how those weaknesses can be responsibly addressed. I also enjoy developing Python-based security tools and automation scripts to make repetitive security tasks more efficient.
